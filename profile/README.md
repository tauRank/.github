# tauRank

**tauRank is a rank tracker for Airbnb and Booking.com listings, built for short-term rental hosts and property managers.** It searches every day from each guest country you choose, shows where your listing ranks in each and the gap between them, and compares your price with the listings a guest weighs you against.

[taurank.com](https://taurank.com) · [Pricing](https://taurank.com/pricing) · [Try a demo](https://taurank.com/demo) · [hello@taurank.com](mailto:hello@taurank.com)

## What it does

- **Tracks Airbnb and Booking.com** listings in one place.
- **Searches from each guest country.** The same city and dates are shown in a different order depending on where the guest searches from, so a ranking belongs to one search, not to a listing. In our first test, the same Timișoara listing ranked between 28 and 129 places apart in Airbnb search results, depending on which country the search came from.
- **Keeps the daily history,** so you read a trend and not a single run.
- **Compares your price** with comparable listings in each country's search.
- **Says how far it looked.** If your listing is not in the pages read, tauRank says "beyond the pages we read", not "not ranked", and a failed search shows as a gap, never as a drop.

## Why "tau"?

The τ in the name is Kendall's tau, a standard measure of how much two rankings agree ([Kendall rank correlation coefficient](https://en.wikipedia.org/wiki/Kendall_rank_correlation_coefficient)). tauRank scores how far guests in different countries see the same order of listings. tauRank is unrelated to any other "tau rank".
